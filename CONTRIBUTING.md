# Contributions

**Pull requests are not accepted.**

This repository is published so others can download, compile, run, and **fork**
under the terms of the GNU GPL v3. The maintainer does not review or merge
external code changes.

If you want to change the game:

1. Fork the repository on GitHub, or clone and keep your own copy.
2. Make any changes you like in your fork.
3. Do not open a pull request against this upstream.

There is **no official support** and **no warranty**.
